## Project Description
This project is a simple two-player Tic Tac Toe game developed using Python. 
The game is played on a 3 × 3 board where two players take turns using X and O.

The program accepts the player's position, checks whether the input is valid 
and whether the selected position is available. It then checks the rows, 
columns and diagonals to determine whether a player has won.

## Main Features
- Two-player gameplay
- 3 × 3 game board
- Position validation
- Detection of occupied positions
- Winner detection
- Draw detection
- X and O player switching
- Basic input error handling

## Technologies Used
- Python
- Visual Studio Code
- GitHub

## Modules Used
- `main.py` – Controls the main game flow
- `board.py` – Displays the game board
- `game_logic.py` – Checks winner and draw conditions
- `input_handler.py` – Handles and validates user input
- `player.py` – Handles player switching

## Expected Outcome
The program allows two players to play Tic Tac Toe through the terminal
and displays the winner or draw when the game ends.
