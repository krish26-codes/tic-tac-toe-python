# Tic Tac Toe Game

## About the Project

This is a simple two-player Tic Tac Toe game made using Python.

The game is played on a 3 × 3 board. Player X and Player O take turns
choosing positions from 1 to 9.

## Features

- Two-player game
- 3 × 3 board
- Invalid input checking
- Already occupied position checking
- Winner checking
- Draw checking
- X and O player switching

## Project Files

- main.py - Main game program
- board.py - Displays the game board
- game_logic.py - Checks winner and draw
- input_handler.py - Handles user input
- player.py - Switches between players

## How to Run

Open the project folder in VS Code and run:

python main.py

## How to Play

Enter a number from 1 to 9 to select a position on the board.

The game continues until one player wins or all positions are filled.
